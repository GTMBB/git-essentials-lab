# 도서관 데모 실행 안내

## 준비 사항

- JDK 17 이상: `java`와 `javac`를 사용할 수 있어야 합니다.
- Python 3.9 이상
- 내려받은 실습 저장소

## 실행 방법

터미널에서 `run.py`가 있는 저장소 최상위 폴더로 이동한 뒤 실행합니다.

```bash
python3 run.py demo
```
